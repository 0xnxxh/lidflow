# LidFlow

原生 macOS 桌面开合效果 App。以 Bendy 的公开演示为视觉参考，独立实现底边锚定透视、柔焦、光影和飞灰。没有复制 Bendy 品牌、音频或界面素材。

## 运行

需要 Xcode / Swift 工具链、macOS 14+；真实合盖需要可读取铰链传感器的 MacBook。

```sh
./script/build_and_run.sh
```

产物：`dist/LidFlow.app`。Codex 的 Run 按钮使用同一脚本。脚本停止正在运行的 LidFlow，再构建、签名和启动；不修改系统权限。`--build` 仅构建，`--verify` 等待本次启动的 GPU 检查报告。

## 使用

- App 启动后自动跟随，无需点击开启。关闭或最小化设置窗口仍在后台工作；退出 App 才结束服务。
- **外观**保留内嵌样例，方便无需录屏权限调整。四种效果分别自动保存三个参数，切换效果、重启后保留；“恢复默认”只重置当前效果。
- **连接与行为**用于验证屏幕访问、传感器读取方式、60/120 fps、清除角度和声音。全屏体验/预览入口已移除。
- 菜单栏仅显示状态、打开设置和退出，不提供跟随开关或体验入口。
- 屏幕访问授权后，盖子低于清除角度时自动捕获内置屏并变换；开盖后恢复。Esc 恢复本次画面，打开到清除角度后自动继续下一次开合。
- 睡眠、锁屏或退出活跃会话时撤除覆盖并暂停读取，恢复后自动连接。没有权限时显示具体原因，避免循环申请；验证权限成功后自动继续。

## 四种效果与参数

- **Silk 柔光**：柔亮丝绸光带和柔焦。
- **Shade 深影**：清晰细节、冷色折面阴影；默认柔焦 35%、阴影 65%。
- **Frost 冰雾**：冰蓝乳白、磨砂模糊和细颗粒。
- **Ash 飞灰**：外周与对角方向逐渐碎裂，原图三角碎片漂移、旋转、缩小；反向开盖重组，停住角度时停住。

透视控制后仰收拢；柔焦同时影响内容与轮廓，0% 关闭柔焦；阴影 0% 关闭额外压暗。Ash 对应控制项为透视、飘散距离和碎片大小。悬停可查看说明。顶部、两侧与上角随投影柔化，底边锚定铰链；黑色设备框只属于内嵌样例容器。

## 屏幕权限

在系统设置“屏幕与系统音频录制”中允许当前 `dist/LidFlow.app`。只捕获屏幕，不捕获音频；画面在内存处理，不保存、不上传。

开发构建为 ad-hoc 签名，重编译可能让系统继续保留旧二进制权限。如果开关已打开仍被拒绝，请移除旧 LidFlow 项，添加**当前** App 并允许，退出再打开。App 中“在 Finder 中显示当前 App”可定位正确路径。授权期间不要重新构建。

有有效代码签名证书时可通过 `LIDFLOW_SIGN_IDENTITY` 指定；不会修改 TCC、创建信任规则或降低签名校验。

## 验证

```sh
swift test
./script/build_and_run.sh --verify
./script/verify-styles.sh
./script/benchmark-render.sh
# 开发专用：用独立临时 App 绘制样例 8 秒，检查后台覆盖层，不捕获桌面。
./script/verify-background-overlay.sh
```

当前 19 项核心测试覆盖角度、平滑、权限状态、各效果保存/迁移/重置、自动跟随生命周期。实际 GPU 检查包括恒等恢复、透明交接、参数范围、边缘柔化、飞灰反转。UI 验证和未验收场景见 [ACCEPTANCE.md](ACCEPTANCE.md)，不可把离屏测试视作真实桌面与物理开合验收。

`artifacts/runtime.json` 只记录角度、状态与时序，不含桌面像素；需 `--diagnostics` 启动参数。直接打开 App 不生成诊断文件。导出的样例 PNG 仅含本地生成素材。

## 实现与范围

- SwiftUI 设置/菜单栏、IOKit HID、ScreenCaptureKit、非激活 AppKit 覆盖面板、Metal；无第三方依赖、无网络访问。
- 传感器后台 120 Hz，独立 CAMetalDisplayLink 线程按目标呈现时间绘制。设置生命周期使用 Dispatch 定时器；后台 activity 阻止 App Nap，但允许显示器和系统正常睡眠。
- 位置/速度连续的整数角度重建，开盖末段逐渐交接到真实桌面；透明帧呈现后撤层。
- 默认清除角度 110°，不是硬件机械最大角度。HID 事件模式、真实睡眠/锁屏、多显示器切换仍需硬件验收。
- 捕获排除自身 App，SDR BGRA，宽度上限 2560；HDR、全 Retina 保真、跨机器分发和公证尚未完成。

研究依据见 [复刻分析](research/复刻分析.md)。
