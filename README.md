# LidFlow

**随开合，自然展开。**

LidFlow 是原生 macOS 桌面效果应用。它读取 MacBook 的铰链角度，让实时桌面随盖子开合倾斜、柔化、变暗，或碎裂成飞灰，再在开盖时重新聚合。

## 安装

[下载最新版本](https://github.com/0xnxxh/lidflow/releases/latest) · [v1.0.0 安装包](https://github.com/0xnxxh/lidflow/releases/download/v1.0.0/LidFlow-v1.0.0.dmg)

需要 **macOS 14+、Apple silicon Mac**。真实开合效果需要可读取铰链传感器的 MacBook 和内置显示器；不能仅凭芯片型号判断传感器兼容性。无兼容传感器时仍可使用内置样例预览。首个安装包为 arm64，不包含 Intel 版本。

1. 打开 DMG，将 `LidFlow.app` 拖入 `Applications`。
2. 打开应用，在 **外观** 中选择效果并查看内置预览。
3. 在 **连接与行为** 中验证屏幕访问，按系统提示授予屏幕录制权限。
4. 如果系统要求，退出并重新打开 LidFlow，然后缓慢开合盖子观察效果。

当前版本采用 **ad-hoc 签名，未经过 Apple Developer ID 签名或公证**。首次打开可能被 Gatekeeper 拦截；确认下载来源后，可在系统设置“隐私与安全性”使用“仍要打开”。应用不会修改系统安全策略或权限数据库。

## 四种效果

| 效果 | 视觉表现 | 可调参数 |
| --- | --- | --- |
| **Silk · 柔光** | 柔亮光带滑过桌面，画面与边缘逐渐柔化 | 透视、柔焦强度、阴影 |
| **Shade · 深影** | 保留较清晰的细节，让冷色阴影沿倾斜画面展开 | 透视、柔焦强度、阴影 |
| **Frost · 冰雾** | 冰蓝雾面、细微颗粒与磨砂玻璃般的柔焦 | 透视、柔焦强度、阴影 |
| **Ash · 飞灰** | 桌面分解成三角碎片，合盖飘散，开盖重新聚合 | 透视、飘散距离、碎片大小 |

每种效果独立保存参数，切换和重启后保留。**恢复默认**只重置当前效果。透视控制后仰与收拢；柔焦同时柔化画面和轮廓，设为 0% 时关闭；阴影设为 0% 时关闭额外压暗。

## 使用方式

应用启动后自动跟随。获得屏幕访问权限后，盖子低于**清除角度**，内置屏的实时桌面开始呈现所选效果；打开到阈值后恢复清晰。默认清除角度为 **110°**，可在 70°–135° 之间调整。

- **随角度变化**：合盖、停住或反向打开时，画面跟随变化，不必等待固定动画播完。
- **后台运行**：关闭或最小化设置窗口后仍继续运行。点击菜单栏图标可重新打开设置或退出。
- **临时恢复**：按 `Esc` 结束本次效果；打开到清除角度后，下次开合自动继续。
- **内置预览**：无需屏幕录制权限即可播放样例、拖动角度或让样例跟随盖子。“跟随盖子”开关只控制内置预览，不关闭后台桌面跟随。
- **睡眠与锁屏**：睡眠、锁屏或会话失活时撤除覆盖并暂停，恢复后尝试重新连接。应用不会阻止系统合盖睡眠。

“连接与行为”还提供后台 120 Hz 角度读取、实验性 HID 事件模式、60 / 120 fps 目标刷新与可选的恢复轻响。实际帧率取决于显示器和负载；HID 事件能否持续回调取决于设备。

## 版本升级

从菜单栏或应用菜单选择 **检查更新…**。也可在 **连接与行为** 中开启或关闭 **自动检查更新**。发现更新后，Sparkle 显示版本信息并引导下载、安装与重新启动。

更新源使用 GitHub Releases，安装包由 **Ed25519** 签名校验。此签名验证更新包的来源和完整性，与 Apple Developer ID 签名、公证不同。版本文件与发布流程见 [发布说明](docs/releasing.md)。

## 隐私与权限

LidFlow 使用 ScreenCaptureKit 读取内置屏画面，并在本机用 Metal 绘制。**画面仅在内存中处理，不保存、不上传；不捕获音频。** 应用没有账号和遥测。Sparkle 会连接 GitHub 检查和下载更新，不发送桌面画面。

macOS 的“屏幕录制”权限允许应用读取屏幕内容，不表示 LidFlow 会录制视频。权限位于“系统设置 → 隐私与安全性 → 屏幕与系统音频录制”，不同系统版本的名称可能略有不同。

ad-hoc 签名的应用在重新构建或更新后，系统可能仍保留旧二进制的权限记录。如果开关已打开但当前版本仍被拒绝：

1. 在系统权限列表中移除旧 LidFlow 条目。
2. 添加并允许当前应用；**在 Finder 中显示当前 App** 可帮助定位。
3. 退出再打开应用，并重新验证屏幕访问。授权期间不要再次构建。

## 常见问题

**没有传感器还能体验吗？** 可以使用内置样例，拖动角度或点击播放；真实桌面效果需要兼容的 MacBook 传感器。

**样例会动，但桌面没有变化？** 检查屏幕权限、传感器状态和清除角度。样例预览与真实桌面跟随是独立路径。

**开盖后效果没有消失？** 先按 `Esc`，确认角度已超过清除角度。仍有异常时，从菜单栏退出再打开，并查看连接状态。

**是否支持外接屏、登录界面和 HDR？** 当前效果只针对内置屏，睡眠和锁屏时暂停。捕获采用 SDR，宽度上限 2560 像素。HDR、全 Retina 捕获、所有机型、HID 事件模式和多显示器切换尚未完成全面验收。

## 从源码构建

需要 Xcode / Swift 工具链。首次构建由 SwiftPM 下载并校验 Sparkle 2.9.3。

```sh
./script/build_and_run.sh            # 构建并运行
./script/build_and_run.sh --build    # 只构建 dist/LidFlow.app
./script/build_and_run.sh --release-build
```

构建成功后，脚本停止旧进程、更新应用包并签名。默认使用 ad-hoc；有有效证书时可通过 `LIDFLOW_SIGN_IDENTITY` 指定签名身份。普通构建不需要 Sparkle 私钥。

```sh
swift test --scratch-path .build/lidflow
./script/build_and_run.sh --verify
./script/verify-styles.sh
./script/benchmark-render.sh
./script/verify-background-overlay.sh
```

19 项核心测试覆盖角度与平滑、权限状态、参数保存/迁移/重置和自动跟随生命周期。GPU 检查覆盖恒等恢复、透明交接、参数范围、边缘柔化和飞灰反转。自动化检查不能替代真实桌面与物理开合的硬件验收。

通过 `--diagnostics <路径>` 显式启动时可记录角度、状态与时序，不包含桌面像素。构建启动脚本写入 `artifacts/runtime.json`，从 Finder 正常打开不生成诊断文件。开发工具用途见 [research/README.md](research/README.md)。
